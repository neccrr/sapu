# Security

Sapu moves files to the Trash, so bugs that could make it touch the wrong files are
treated as security issues: safety-check bypasses, wrong paths after a re-scan,
iCloud deletes without consent, symlink tricks, and so on.

Please report them privately through GitHub's **Security → Report a vulnerability**
on this repository rather than in a public issue. Include steps to reproduce and,
if you can, the relevant lines from the log (📜 Logs → Copy).
